## 从源码构建

仓库**不提交**任何 debug APK，请从源码自行构建（或用 GitHub Actions 自动出包）。

**前置条件**
- JDK 17
- Android SDK（Platform 34、Build-Tools 34.0.0）
- Gradle 8.2（或用 Android Studio，它会自动拉取）

**方式一：Android Studio（最直接）**
用 Android Studio 打开 `KioskShell/` 目录 → 等待 Gradle 同步 → `Build → Build Bundle(s)/APK(s) → Build APK(s)`。
产物：`app/build/outputs/apk/debug/app-debug.apk`。

**方式二：GitHub Actions（免装环境）**
把仓库推到 GitHub 后，`.github/workflows/build.yml` 会在 push 到 `main`/`master` 或手动触发时自动编译，到 Actions 页面下载 `KioskShell-debug-apk` 产物即可。

**方式三：命令行**
```bash
# 需要本地有 Gradle 8.2（仓库未附带 gradlew 包装脚本；装好 Gradle 后也可执行 `gradle wrapper` 生成）
export ANDROID_HOME=/path/to/android-sdk
gradle assembleDebug --no-daemon
```
> 想提交 `gradlew` 让他人免装 Gradle：在装有 Gradle 8.2 的机器上执行 `gradle wrapper --gradle-version 8.2`，把生成的 `gradlew`、`gradlew.bat`、`gradle/wrapper/` 一并提交。

## 跨品牌通用吗？—— 能，而且大部分已经做完了

先说结论：**壳本身不认品牌**。换一台电视要重做的事情只有两件：装包、给无障碍权限。剩下的探测全是运行时做的。

| 能力 | 怎么实现的 | 跨品牌？ |
|---|---|---|
| 锁桌面 | 无障碍服务盯着前台应用，跑偏就拉回来 | ✅ 全品牌通吃，这是主力锁法 |
| 找到系统桌面 | 运行时问系统"按 HOME 会落到谁"（`resolveActivity`），探测不到再列出候选、**系统应用优先** | ✅ 不维护品牌表，海信/小米/索尼/TCL/当贝自动认出来 |
| 临时回原桌面 | 用上一步探测到的包名**显式**启动，不发隐式 HOME（否则尊重默认桌面的电视上会打回自己） | ✅ v1.28 修 |
| 启动目标应用 | `getLaunchIntentForPackage` + 试 LEANBACK/LAUNCHER 两个 category | ✅ |
| 时长管控 / 门禁 / 锁屏页 | 纯应用层 | ✅ |
| 悬浮窗（到点盖休息页） | 应用权限 | ✅ 都能给 |
| 远程开无障碍 | `settings put secure`，被固件拦就走 `pm grant WRITE_SECURE_SETTINGS` 再写一次 | ⚠️ 小米/MIUI 一定走第二条；个别定制固件两条都不行，只能电视上手动点一下 |
| Device Owner / Lock Task | 依赖 `android.software.device_admin` 特性 | ❌ 海信等固件阉了这个特性，直接没有；索尼/原生 Android TV 一般有 |

**VIDAA / HomeOS（海信自家 Linux 那套）装不了**，不是兼容性问题，是它根本没有 Android 运行时。这种电视的正解是外接一个安卓盒子（百来块），壳装盒子上，电视只当屏幕用。

### 一条命令装完（Windows / macOS / Linux 通用）

把「连接 → 体检 → 装包 → 开无障碍 → 回读验证」全打在 `tools/kiosk.py` 里，只依赖 Python 3 和 adb。Windows 上把 `python3` 换成 `python`：

```bash
python3 tools/kiosk.py discover              # 找电视（已连接的 + 局域网广播的）
python3 tools/kiosk.py doctor 192.168.1.50   # 体检：系统版本、能不能强锁、无障碍开没开
python3 tools/kiosk.py install 192.168.1.50  # 装 APK + 开无障碍，装完即可用
```

装完再去电视上操作三步（选应用 / 改密码），见 [README 的 30 秒上手](../README.md#30-秒上手)。

脚本会先打印电视品牌 / 型号 / Android 版本 / 有没有 Device Admin 特性 / 系统桌面包名，再动手；每一步都有回读校验（无障碍写完会 `settings get` 回读确认，不是设完就完）。

其他子命令：

| 命令 | 干什么 |
|---|---|
| `watchdog` | 只开无障碍（开机自启、HOME 拉回都靠它） |
| `overlay` | 恢复悬浮窗权限（可选，海信会周期性回收） |
| `recover-launcher` | 救命：重新启用被停用的系统桌面 |
| `uninstall` | 卸载，配置一起清掉 |

### 各品牌已知差异（实测 + 文档，脚本里也有对应提示）

| 品牌 | ADB 开关 | 无障碍远程开启 | Device Owner |
|---|---|---|---|
| 海信 / Vidda（JUUI） | 要「USB 调试」+「网络调试」两个都开 | 标准路径即可 | ❌ 无 device_admin 特性 |
| 小米 / Redmi（MIUI） | 「网络调试」单独一项 | 需 `pm grant WRITE_SECURE_SETTINGS`（脚本自动） | 多数可以，但要先退出小米账号 |
| 索尼（Android TV） | 原生开发者选项 | 标准路径 | ✅ 一般可以 |
| TCL / 雷鸟 | 部分机型只有「无线调试」，要先配对 | 标准路径 | 视固件 |
| 当贝 / 天猫 / 腾讯极光盒子 | 原生开发者选项 | 标准路径 | ✅ 盒子一般可以 |

**每次重装 APK，无障碍授权会失效**（系统行为，绕不过），脚本的 `-EnableWatchdog` 就是补这个的；不重装就不用管。

### 海信 JUUI / VIDAA 的强锁死路（三种都实测过，别再试第四遍）

实测平台：海信 `VIDAA_TV` / Android 11 / SDK 30。结论：**强锁（Device Owner + Lock Task）在这台电视上做不到**，四条路子全被固件挡死。

| 尝试 | 结果 |
|---|---|
| `pm list features` 查 `android.software.device_admin` | **空** —— 特性被阉掉，系统层面就没有这个能力 |
| `adb shell dpm set-device-owner com.kidstv.kiosk/.KioskAdmin` | `java.lang.RuntimeException: Can't set package ... as device owner.` 直接拒绝 |
| 应用内 `RoleManager.ROLE_HOME` 申请默认桌面 | 不弹确认框（`cmd role` 在这台电视上也是 `Unknown command`） |
| `adb shell cmd package set-home-activity com.kidstv.kiosk/.HomeAlias` | **返回 `Success`，但完全无效** |

最后一条特别容易骗人 —— 命令自己说成功了，实际按 HOME 还是回聚好看。`logcat` 抓到的时间线：

```
14:01:28.326  START ... cat=[HOME] cmp=com.jamdeo.tv.vod/com.ju.main.launcher.LauncherActivity
14:01:28.584  START ... cmp=com.kidstv.kiosk/.MainActivity      ← 258ms 后看门狗拉回
```

也就是说：**HOME 被固件钉死在聚好看，任何"默认桌面"设置它都不认**。现在之所以能锁住，是因为看门狗在 258 毫秒内把人拉回来，观感上是"闪一下"。

这台电视上就剩三个选项：

1. **保持看门狗**（推荐）：零风险，随时从家长菜单退出，孩子基本感知不到闪动。
2. **停用系统桌面**：`adb shell pm disable-user --user 0 com.jamdeo.tv.vod`，HOME 物理上没有聚好看可选。代价是电视上暂时没有原桌面，**儿童桌面一旦出问题只能靠电脑 ADB 恢复**（`adb shell pm enable com.jamdeo.tv.vod`），聚好看的影视入口也一起没了。
3. **外接安卓盒子**：盒子设成 Device Owner 后 HOME / 返回 / 最近任务全失效，是唯一真正的强锁。电视只当屏幕，壳装盒子上，逻辑一行都不用改。

## 锁法：看门狗模式（唯一能锁住又能自己退出的）

先说结论：**靠"把自己设成默认桌面"在海信这类固件上完全无效**，系统桌面永远是聚好看。实测：

| 方法 | 结果 |
|---|---|
| 家长菜单里设默认桌面 | 无效，按 HOME 还是回聚好看 |
| HOME 角色 / `set-home-activity` | 命令回 Success、角色也归本应用，`resolve-activity` 仍解析到聚好看 |
| 停用系统桌面（`pm disable-user`） | **有效，但退不回来**：普通应用没权限启用别的应用，电视的应用信息页也没有「启用」按钮（已截图确认）。这条路已废弃 |
| Device Owner | 系统里没有 `android.software.device_admin` 特性，`dpm` 必定失败 |

**现在用的是看门狗**：系统桌面原封不动，应用里挂一个无障碍服务盯着"当前前台是哪个应用"，
发现跑到不是儿童桌面、也不是目标应用的地方，立刻把桌面拉回来（实测切到当贝市场后 2 秒内弹回）。

- 需要家长给一次 **无障碍权限**：家长菜单 → 开启儿童桌面 → 会跳转过去，找到「儿童桌面」打开开关。
- **两种退出，别搞混**（家长菜单里各有一个按钮）：

| 按钮 | 效果 | 开机后 |
|---|---|---|
| **临时回系统桌面（本次放行）** | 这一轮回系统桌面自己用，锁定状态不动、看门狗不再弹 | ✅ 仍然自动进儿童桌面 |
| **退出儿童桌面（不自动恢复锁定）** | 彻底关掉：撤掉桌面身份、看门狗停用 | ❌ 直接进系统桌面 |

（按钮上的名字是运行时探测出来的：海信显示「临时回聚好看」，小米显示「临时回小米电视桌面」……）

  **重新打开「儿童桌面」就自动结束放行**（聚好看的应用列表里点它的图标即可），
  不需要再进菜单点结束——省得忘。重启电视同样会结束放行。
- ⚠️ **每次重装 APK，无障碍授权会失效**，要重新给一次（或重装后进菜单点一次「开启儿童桌面」）。
- 家长要进系统设置时，菜单里的「打开系统设置」会先让看门狗暂停 10 分钟，不会被弹回来。

**成本**：多一个无障碍服务常驻；从跳到聚好看再到被弹回，中间会闪一下（约 0.2–2 秒）。


## 安装（弱锁）

**完整步骤见 [README 的 30 秒上手](../README.md#30-秒上手)**，这里只补细节：

1. 电视上先装好那个要给孩子看的视频 App（比如夸克网盘 TV 版、BoxPlayer），确认能登录、能播放再往下走
2. 拷最新的 `KioskShell-v*-debug.apk`（GitHub Releases / Actions 产物，或[从源码构建](#从源码构建)；版本号取最大的那个）到 U 盘，插电视安装
3. 打开「儿童桌面」
4. **长按遥控器菜单键 2 秒** → 输入默认密码 `123456`
5. 家长菜单 →「**选择应用**」→ 从列表里勾选刚才装的那个视频 App（可多选）→ 确定
   → 桌面立刻变成它的图标和名字
6. 家长菜单 →「**开启儿童桌面**」→ 按提示打开无障碍权限（**开机自启就是这一步**）
7. 家长菜单 →「修改密码」，把 `123456` 换掉

> **第 5 步不做也不会坏**：桌面显示「还没选应用」，点它只弹一句提示，不白屏也不崩。选完立刻生效，不用重启。

> **「设为默认桌面」不用管**：新版家长菜单里已经没有这个入口。海信/聚好看这类固件会无视默认桌面设置（[四种方法实测全部无效](#海信-juui--vidda-的强锁死路三种都实测过别再试第四遍)），能锁住靠的是无障碍看门狗。在原生 Android TV / 索尼上想少闪一下，可以自己去系统设置里把儿童桌面设为默认桌面——不做也不影响使用。

## 开机自启：靠无障碍，不靠悬浮窗（v1.27 重做）

开机把儿童桌面拉起来，最大的坑不是"听不到开机广播"，而是 **Android 10 起禁止后台启动界面**——从广播里 `startActivity` 会被静默拦截，界面上毫无反应，也不报错。这就是"代码明明写对了，开机却停在原桌面"的真正原因。

豁免条件只有两条，本项目走第二条：

| 豁免条件 | 可靠性 | 本项目怎么用 |
|---|---|---|
| 拥有 `SYSTEM_ALERT_WINDOW`（悬浮窗）权限 | ❌ 海信 / VIDAA 会周期性回收，实测 4–6 分钟一次 | 只在有权限时顺手先拉一次，省一两秒，**不是依赖** |
| **应用有被系统绑定的服务**（无障碍服务就是） | ✅ 系统自己绑定，不受该限制 | **主路径**：看门狗 `KioskWatchService` 负责拉起 |

所以流程是：`BootReceiver` 清掉「本次放行」→ 拉起计时服务 → 看门狗在开机后 3 分钟内**主动重试**拉起儿童桌面（那时候可能一个窗口事件都收不到，纯事件驱动会干等）。

其余门槛照旧处理：

| 门槛 | 说明 | 处理 |
|---|---|---|
| 广播名不统一 | 有的电视/盒子发 `QUICKBOOT_POWERON` 而不是 `BOOT_COMPLETED` | 两个都听 |
| stopped 状态 | Android 3.1+，安装后从没打开过的应用**收不到开机广播** | 无解，装完手动打开一次；README 和家长菜单都写了 |
| 厂商自启动管理 | 海信/小米等固件默认掐掉第三方应用的后台活动和自启动 | **应用内无解**，去电视设置里把儿童桌面设为「允许」 |
| 更新 APK 后无障碍被关 | 系统升级应用时会自动关掉它的无障碍服务 | 重新打开一次（最容易被忽略的一条） |

**实测（2026-10-26，海信 VIDAA_TV / Android 11）**：无障碍开着时重启，几秒内自动进儿童桌面；这时把悬浮窗权限设成 `ignore` 也一样能拉起。

三次重启的完整时间线（adb 轮询抓的，不是估算）：

| 版本 | 落地耗时 | 悬浮窗权限 | 中间过程 |
|---|---|---|---|
| v1.27 | 34 秒 | `ignore` | 直接进儿童桌面 |
| v1.27 | 38 秒 | `ignore` | 直接进儿童桌面 |
| v1.28 | **32 秒** | `ignore` | 28 秒时先落聚好看（`VipAlbumActivity`），32 秒被看门狗拉回 |

也就是说：**开机自启跟悬浮窗权限完全无关**，只要 `locked=true` + 无障碍开着就成立。中间那 4 秒的聚好看属于正常——固件开机后会先起自己的桌面，看门狗随后接管。

### 怎么确认自启正常

家长菜单 → `开机自启检查`，逐项打勾：

1. **锁定**：退出过儿童桌面的开机不会自启（有意如此）
2. **无障碍**：开机拉起的关键，没开一定失败
3. **开机广播**：已注册
4. **默认桌面**：是儿童桌面最稳（系统自己启动它）；不是也不影响，看门狗会拉回来
5. **悬浮窗**：可选，只影响锁屏页盖得快不快

**开机一律结束「本次放行」**——家长放行只是这一轮，重启后照旧锁回去。

## 选目标应用（可多选）/ 装哪个 App

代码里**不写死任何包名**，装哪些由你在电视上选，**可以一次勾多个**：

```
长按菜单键 2 秒 → 过验证 → 选择应用 → 勾选（可多选）→ 确定
```

- 桌面会为每个勾选的应用排一张卡片，**点哪张进哪个**（1 个是大卡、2 个中卡、3 个及以上小卡）
- 看门狗放行所有勾选的应用，切到其中任何一个都不会被弹回
- 强锁白名单（`setLockTaskPackages`）同步写入全部勾选项
- 弹窗里「全不选」= 谁都不锁：桌面还在，但点图标不启动任何 App
- 旧版单选的数据会自动迁移成多选的第一项，升级不丢

选完立刻生效，`applyPolicy` 会马上刷新强锁白名单，**不需要重装、不需要改代码**。

常见几个可以锁的（只是参考，不是内置默认值）：

| App | 包名 | 优点 | 注意 |
|---|---|---|---|
| 夸克网盘 TV 版 | `com.quark.yun.tv` | 官方、手机扫码登录、有续播/连播/倍速/字幕音轨 | 界面是文件列表，没有爆米花那种海报墙；**非会员会限速，部分资源只给试看 2 分钟** |
| BoxPlayer | — | 开源，原生支持阿里/百度/115/夸克等十几种网盘，自动刮削海报墙 | 包体大、配置项多 |
| Ghosten Player | — | 15MB，支持阿里/夸克/WebDAV，有海报墙和跳过片头片尾 | 个人开发，更新不一定及时 |
| 网易爆米花 | `com.netease.filmlytv` | 海报墙漂亮、刮削准 | **不支持夸克网盘直连**，只认阿里/百度/115/天翼/WebDAV/SMB；夸克得先用 Alist 挂成 WebDAV |

### 悬浮窗权限（v1.27 起可选，可以不给）

到点弹休息页、开机拉起界面，**都已改走无障碍通道**，不再依赖这个权限。给了唯一的好处是锁屏页能盖得更快、更靠前。

海信 / VIDAA 有个已知毛病：在电视设置页点「允许」，4–6 分钟后系统会自己关掉，`logcat` 里不留任何记录（多次实测）。用 ADB 直接写 appops 比设置页稳，但也不是永久的——掉了再跑一次就行：

```bash
adb connect <电视IP>:5555
adb shell cmd appops set com.kidstv.kiosk SYSTEM_ALERT_WINDOW allow
```

```bash
# 三平台通用
python3 tools/kiosk.py overlay <电视IP>
```

Windows 用户也可以直接双击 `tools/fix-overlay.bat`（本质就是上面这条命令，会提示输 IP）。
adb 找法：`PATH` → `%LOCALAPPDATA%\Android\Sdk\platform-tools` → `%ANDROID_HOME%` → macOS 的 `~/Library/Android/sdk` → 项目 `tools/` 目录；也可以用环境变量 `ADB` 或参数 `--adb` 指定。

> **为什么 app 不能自己恢复**：`SYSTEM_ALERT_WINDOW` 是特殊权限（appops），普通应用连 `MANAGE_APP_OPS_MODES` 都拿不到，只能靠 shell / root 写入。所以 app 端只提供"显示本机 IP + 命令"，不做自动恢复——也正因为如此，v1.27 把锁屏、开机都搬到了不依赖它的通道上。

## 不用 U 盘：Wi-Fi 远程安装

做法跟 CleanYourTV 那套一样：电视开 ADB，电脑在同一个 WiFi 里连上去推包。装一次以后改代码重编，也不用再找 U 盘。

**电视这边（只做一次）**

1. 电视和电脑连同一个 WiFi（不要连访客网络）
2. 开开发者选项 + ADB（路径见下面「找不到 ADB 开关」一节）
3. 电视上的 IP：设置 → 网络 → 点开当前网络 → IPv4 地址（一般是 `192.168.x.x`）

### 启动后自动进入应用（默认关闭，v1.12 起）

桌面默认**停在原地，等孩子自己按 OK 进去**。需要"开机直奔播放器"的，在 观看时长设置 →「自动进入应用」打开（打开后停留 4 秒自动进）。

打开后要注意：

- **家长怎么进菜单**：进桌面后**按一下遥控器任意键**（方向键即可），自动跳转立刻取消，然后长按菜单键 2 秒。
  HOME / 返回 / 音量 / OK 不算"取消键"，因为按 HOME 回桌面后要能继续自动进应用。
- **孩子按 OK**：立刻进，不用等 4 秒。
- **为什么不是一到就跳**：家长要在桌面上完成「长按 2 秒」，如果 0.5 秒就跳走了，家长永远进不去。

### USB 调试 / 网络调试 / 无线调试，到底开哪个

名字五花八门（有的叫「远程调试」「Debug over network」「调试模式」），本质上只有三种：

| 开关 | 开了管什么 | 什么时候开 |
|---|---|---|
| **USB 调试** | 打开 adbd。很多电视固件顺手就让 adbd 监听 5555（电视没有可用的 USB 口，厂商默认走网络） | **先只开这个**，然后跑 `kiosk.py discover`，通了就不用管后面两种 |
| **网络调试 / ADB over network** | 明确把 adbd 切到 TCP 5555 | USB 调试开了但 5555 不通，就来开这个。海信/Vidda 多数是这一档 |
| **无线调试（配对码）** | Android 11+ 的新机制，端口是随机的（3 万多），并且**必须先配对**才能连 | 只有前两种都找不到时才用，见下面 |

判断顺序就一句：**先开 USB 调试 → 扫不到 5555 → 再找网络调试**。

如果电视上只有「无线调试」，那个六位配对码那一套，用 adb 原生命令（三个平台一样）：

```bash
adb mdns services                        # 看电视广播出来的地址和端口
adb pair 192.168.1.50:41923 123456       # 电视上显示的配对端口 + 六位配对码
adb connect 192.168.1.50:37201           # 电视上显示的连接端口
```

两个端口不一样，配对码是一次性的，过期就回电视上重新生成。

### 先确认这台电视是不是安卓

Vidda / 海信 分两套系统，能力完全不同：

| 系统 | 怎么认 | 能装 APK 吗 | 有 ADB 吗 |
|---|---|---|---|
| **JUUI**（基于 Android，国内近年 Vidda/海信主流） | 设置里能查到 Android 版本；首页有「我的应用」，能装第三方 APK | ✅ | ✅ 只是藏得深 |
| **VIDAA / HomeOS**（海信自家 Linux） | 设置 → 关于 → 只有 VIDAA 版本号，没有 Android 版本；应用只能从自带商店装 | ❌ 装不了 | ❌ 没有 adb 这回事 |

**如果是 VIDAA，别再折腾了**：本项目的 APK 在它上面根本装不上。正解是买个安卓盒子（当贝 / 小米 / 腾讯极光，百来块），把儿童桌面装盒子上，盒子的 HDMI 接电视，电视只当屏幕。**壳的逻辑完全不用改**，装到盒子上一样用。

### 找不到 ADB 开关（海信 / Vidda）

按成功率从高到低试，**试完一档不行再下一档**：

1. **常规入口**：设置 → 关于本机 → 在「版本号」上连按 OK 8–10 次 → 提示「已进入开发者模式」→ 返回设置 → 开发者选项 → 打开「USB 调试」；有「网络调试 / ADB 调试」的一并打开。有的固件在「账户与安全」里还有单独的「ADB 调试」开关。
2. **工厂模式（海信系通用）**：设置 → 声音 → **音量平衡** → 停在那一项按遥控器数字键 **1969** → 进工厂菜单 → 找 `ADB` / `USB 调试` / `调试模式` 打开。
   - 遥控器没数字键：在「音量平衡」页交替反复按 **菜单键 + 确认键**
   - 遥控器有红绿黄蓝键：在「音量平衡」页按 **红 → 绿 → 黄 → 蓝**
   - 部分机型是数字键 **0-8-1-6**
   ⚠️ 工厂菜单里除了 ADB 别的别动，白平衡、Tofac、屏参那一类改错会黑屏。
3. **老款海信的隐藏原生设置**：设置 → 关于 → 本机信息 → 连按**菜单键** 4–5 次 → 跳进原生 Android 设置 → 关于 → 版本号连按 7 次 → 开发者选项 → USB 调试。
4. **VIDAA 时代的调试授权**：我的应用 → VIDAA 助手 → 设置 → 电视调试授权（这只对老 VIDAA 有效，且不保证能连 adb）。

打开后电视会监听 5555，这时回到电脑跑 `python3 tools/kiosk.py discover` 就能扫到。

### 不想开 ADB 的两个替代方案

ADB 只是"装包"的一种方式，不是唯一：

| 方案 | 做法 | 适用 |
|---|---|---|
| **U 盘**（最稳） | 拷 APK 到 U 盘 → 插电视 → 文件管理/电视管家找到它 → 安装 | 一次性装完就不动了 |
| **当贝市场远程推送**（不用 ADB） | 先用 U 盘装一次当贝市场 → 打开 → 我的/管理 → **远程推送** → 屏幕上显示一个网址 → 电脑或手机浏览器打开那个网址 → 上传 APK → 电视自动安装 | 以后想换版本，不用再拔插 U 盘 |

当贝那条路本质是"电视上跑了个网页服务收文件"，不需要开发者选项，也不用开 ADB，比折腾工厂模式省事。

**电脑这边**

一条命令装完（Windows 上把 `python3` 换成 `python`）：

```bash
python3 tools/kiosk.py discover              # 找电视
python3 tools/kiosk.py doctor 192.168.1.50   # 体检，顺便确认要不要强锁
python3 tools/kiosk.py install 192.168.1.50  # 装 + 开无障碍
```

第一次连的时候电视会弹「是否允许 USB 调试」，用遥控器选**允许**（有「一律允许」就勾上）。脚本会自己等到你按完。

**几个可选动作**

| 想要 | 命令 |
|---|---|
| 只要开机自启 / HOME 拉回（开机自启的唯一前提） | `python3 tools/kiosk.py watchdog <IP>` |
| 让锁屏页盖得更快（可选，海信会周期性回收） | `python3 tools/kiosk.py overlay <IP>` |
| 卸载干净（连配置一起） | `python3 tools/kiosk.py uninstall <IP>` |
| 救命：系统桌面被停用了 | `python3 tools/kiosk.py recover-launcher <IP>` |

**强锁（Device Owner）和激进锁法没有封装进脚本**，因为风险高、而且多数国产固件根本不支持。要试就手敲：

```bash
# 强锁：电视不能登录任何账号，否则会被拒绝
adb shell dpm set-device-owner com.kidstv.kiosk/.KioskAdmin

# 激进锁法：停用系统桌面，HOME 物理上只剩儿童桌面（崩了按 HOME 没反应，慎用）
adb shell pm disable-user --user 0 <系统桌面包名>
```

**装完请把 ADB 关掉。** ADB 开着的时候，同一个 WiFi 里任何一台电脑都能对这个电视装包、改设置、看你的数据。要用再打开，这是 CleanYourTV 文档里也没做、但你应该自己补的一步。

**连不上时按这个顺序查**

| 现象 | 原因 |
|---|---|
| `cannot connect` | ADB 开关没开；或电视重启后自动关了（部分海信/小米固件如此） |
| 一直 `unauthorized` | 电视上的授权弹窗没按，或者按了「取消」 |
| 找得到 IP 但扫不到 5555 | 电视和电脑不在一个网段（双频分离、访客网络） |
| `INSTALL_FAILED_UPDATE_INCOMPATIBLE` | 签名不一致，先 `-Uninstall` 再装 |
| `INSTALL_FAILED_DEVICE_OWNER` | 已经是设备所有者，得先在电视的家长菜单里撤销 |


## 观看时长（家长菜单 → 观看时长设置）

进去是一个独立页面，**左右键调数值，上下键换行**，改完立刻生效，不用重启：

| 行 | 默认 | 可选 |
|---|---|---|
| 每次最多观看 | 25 分钟 | 不限 / 10 / 15 / 20 / 25 / 30 / 40 / 45 / 60 |
| 每次休息 | 5 分钟 | 不休息 / 1 / 3 / 5 / 10 / 15 / 20 / 30 |
| 每天总时长 | 60 分钟 | 不限 / 30 / 45 / 60 / 90 / 120 / 150 / 180 |
| 家长验证方式 | 纯数字密码 | 纯数字 / 两位数加减 / 两位数乘除 |
| 自动进入应用 | 关 | 开 / 关（打开后停留 4 秒自动进应用） |
| 休息语音 | 开 | 开 / 关 |
| 试听这句话 | — | 按 OK 播放 |
| 今天已看 XX 分钟 | — | 按 OK 清零 |
| 恢复默认设置 | — | 按 OK |

**到点长什么样**

- 单次到点 → 全屏「休息一下」+ `05:00` 倒计时，同时**播一句语音**，到点自动解开，孩子回到原来那集继续看
- 每日用完 → 全屏「今天的时间用完了 / 明天再来」，另播一句，第二天零点自动解
- 两种锁屏页：返回键无效，长按菜单键 2 秒 + 验证才能动（休息页可以「提前结束」或「关闭时长管控」，日额度页可以「再给 30/60 分钟」）
- 孩子按 HOME 躲回桌面，桌面会立刻把锁屏页重新推上去，桌面上的大图标也点不进去

**只算真的在看的时间。** 桌面在前台、电视息屏待机、休息中、今天已超额，这四种情况都不计时。开机时间、菜单里停留的时间也不计入。

**家长验证是同一把钥匙**：改密码、改时长、退出锁定，全都要它。孩子学会改时间，前面所有锁都白做，所以这一项没有留后门。

## 家长验证方式（三档）

| 档位 | 出什么题 | 说明 |
|---|---|---|
| 纯数字密码 | 固定 4–8 位数字 | 默认，沿用 `123456`。升级不会被锁在门外 |
| 两位数加减 | 如 `68 + 47`、`83 - 46`，**必带进位/借位** | 一到二年级的坎，学龄前算不出 |
| 两位数乘除 | 如 `24 × 7`、`96 ÷ 8`（保证整除） | 背熟乘法口诀的孩子可能算得出，但已经很少见 |

- 每次弹窗**现出一道新题**，家长现场算，孩子记住上次答案没用。
- **答错换一道新题**，连错 3 次锁 60 秒，期间键盘真的按不动。
- 键盘是**自绘的**，不是系统输入框 —— 电视上 EditText 一获得焦点，Leanback 输入法会整屏盖住弹窗，部分海信固件干脆没有输入法，按 OK 没反应。
- 冷却用 `elapsedRealtime` 计时，**调系统时间绕不过去**；失败次数和当前题目都落盘，杀进程重进一样认账。

## 到点语音

| 时机 | 说什么 |
|---|---|
| 休息刚开始 | 「小朋友，我累了，休息一下吧」 |
| 每天额度用完 | 「小朋友，今天看得够多啦，明天再来找我玩」 |
| 设置页「试听这句话」 | 播第一句，用来确认电视上响不响、音量合不合适 |

- 音频是**离线合成好打包在 APK 里**（两条共 68KB，卡通童声音色），不依赖电视有没有中文语音引擎 —— 海信和多数电视都没有。
- 请求的是 `AUDIOFOCUS_GAIN_TRANSIENT_MAY_DUCK`：底下的播放器会自动把声音压下去，语音不用跟动画片抢音量；播完立刻还回去。
- **同一次休息只播一次**。后台每 8 秒会把锁屏页重新拉起来一次，语音跟着页面走的话，休息 5 分钟能听见几十遍 —— 所以用「休息截止时间戳」和「今天日期」做锚点去重。
- 关掉开关后，连试听都不播。

## 强锁（可选，更彻底）

### 前提

- 电视没有登录任何账号（设置 → 账号）。有账号的话 `dpm` 会拒绝，得先删账号
- 电脑装了 adb

### 步骤

```bash
# 1. 电视上：设置 → 关于本机 → 版本号连点 7 次，开开发者选项
#    设置 → 开发者选项 → 开启 USB 调试 或 网络调试（记下电视 IP）

# 2. 电脑上
adb connect 192.168.1.x:5555
adb devices                        # 确认连上

# 3. 设为 Device Owner
adb shell dpm set-device-owner com.kidstv.kiosk/.KioskAdmin
```

看到 `Success: Device owner set to package com.kidstv.kiosk` 就成了。
回到本应用，`家长菜单` 里会显示「强锁（Device Owner + Lock Task）」。

强锁下：
- HOME 键、返回键、最近任务全部失效
- 通知栏拉不下来
- 遥控器的「设置」键也进不去系统设置（非白名单应用起不来）
- 只有长按菜单键 2 秒 + 密码，才能进家长菜单

## 怎么恢复（重要，先看这段）

按顺序试，前一条不行再试下一条：

1. **家长菜单 → 撤销 Device Owner**
   长按菜单键 2 秒 → 密码 → 最后一项
2. **ADB 撤销**
   ```bash
   adb shell dpm remove-active-admin com.kidstv.kiosk/.KioskAdmin
   ```
   如果报 `is not testOnly`，说明这个 APK 没有标记 testOnly，走第 3 条
3. **恢复出厂设置**
   电视 设置 → 系统 → 恢复出厂。这会清掉所有内容，但 Device Owner 一定会被清掉

**如果 App 进入崩溃循环、连家长菜单都进不去**，只能走第 2 或第 3 条。所以强锁前一定要先确认 App 在弱锁模式下稳定运行。

| 项 | 作用 | 什么时候出现 |
|---|---|---|
| 打开应用 | 手动启动已选的目标 App | 总是 |
| 观看时长 | 单次 / 休息 / 每日额度、总开关、清空今日已用 | 总是 |
| **开启儿童桌面** | 开始锁定，并引导你去开无障碍权限 | 未锁定时 |

| 悬浮窗权限（可选） | v1.27 起不再必需，给了只让锁屏页盖得更快 | 没给权限时 |
| 开机自启检查 | 五项逐条自检（锁定 / 无障碍 / 广播 / 默认桌面 / 悬浮窗） | 总是 |
| 系统设置 | 跳系统设置，同时把看门狗暂停 10 分钟，免得一秒被弹回来 | 总是 |

## 已知问题

1. **弱锁挡不住懂行的孩子。** 遥控器上的「设置」键能进系统设置，能改回默认桌面。这是 Android 的限制，App 层面无解。
2. **强锁需要设备没有账号。** 海信电视如果登录了海信账号，`dpm set-device-owner` 会拒绝。要么删账号，要么恢复出厂后再设。
3. **目标 App 自己崩了会回到本应用的桌面**，不是回到系统桌面——这是好事，孩子还是出不去。
4. **部分海信固件屏蔽了 `dpm` 命令。** 报 `Unknown command` 或 `Permission denied` 就没戏，只能用弱锁。
5. **锁 Task 会隐藏状态栏**，电视上不显示时间。要显示时间得把 `setLockTaskFeatures` 改成 `LOCK_TASK_FEATURE_SYSTEM_INFO`（`Kiosk.kt` 里改）。
6. **改了目标应用包名要重新 applyPolicy。** 家长菜单里改完会自动调用，但强锁下建议重启一次应用。
7. **到点锁屏、开机拉起都不再依赖悬浮窗**（v1.27）。它们走的是无障碍服务——"应用有被系统绑定的服务"是 Android 10 后台启动限制的豁免情形之一。**但反过来，无障碍被关掉这两项就都会失效**，而每次更新 APK 系统都会自动关掉它，需要重新打开一次。
8. **海信 / VIDAA 会周期性回收悬浮窗权限。** ADB 写进去的也照样被收（实测几分钟内变回 `ignore`）。现在已经不影响主要功能，只是锁屏页偶尔盖得慢一点；别为它折腾了。
8. **计时的口径是「桌面不在前台」。** 家长自己进系统设置、进别的应用也会被算进去。发现数字不对，家长菜单里「清空今天已用」即可。
9. **休息时间到点自动解开，不弹密码。** 这是有意的——孩子被强行打断已经够了，密码只用于「提前结束」和「加时」。
10. **改系统时间可以骗过每日额度。** 判断今天靠本机日期，把电视时间调到明天就重置了。电视上没找到好办法防（要读网络时间得联网+额外权限）。
11. **电视静音或媒体音量为 0 时，语音不会响。** 没有去改系统音量：那既越权，家长也可能就是故意静音的。要强制出声只能申请改音量的权限，没做。
12. **休息时目标 App 的画面被盖住了，声音可能还在。** 我们请求的是 duck（压低而不是暂停）；如果对方不响应音频焦点，动画片的声音会继续。控制不了第三方播放器的行为。
13. **两位数加减对已经会心算的二年级孩子不算障碍。** 要更严就选「两位数乘除」档。
14. **纯数字档要按 4–8 次**，比用遥控器数字键慢一点。嫌慢就换成数学题档，只按两三位。
15. **夸克网盘 TV 版只能看整个网盘。** 登录后所有视频文件都在列表里，没有「只显示某个文件夹」的功能。给孩子的账号里只放那几部最稳；同一账号靠文件夹自律，防不住翻。
16. **限速不是播放器的问题，换谁都一样。** 非会员的限速 / 试看 2 分钟来自网盘服务端，挂 Alist 转 WebDAV 也绕不过去。
17. **升级到 1.3 后桌面可能显示「还没选应用」。** 因为去掉了写死的默认包名。长按菜单键 2 秒选一次即可，之后一直记得。
18. **家长菜单里的「临时回原桌面」在某些电视上曾经点了没反应**（v1.28 已修）。如果你用的是旧版 APK，升级一下；临时应急可以直接按遥控器的 HOME 键。

## 加一套新皮肤（以「墨绿森林」为例）

皮肤 = 一组颜色 + 7 个 drawable + 2 个主题样式，布局一行都不用改：

1. `res/values/colors.xml` 加一组 `forest_*`（命名跟着 `cream_*` / `space_*` 抄）
2. `res/drawable/` 里把 7 个 `bg_*_cream.xml` 复制成 `bg_*_forest.xml`，把里面的 `cream_*` 颜色替换成 `forest_*`
3. `res/values/themes.xml` 加两行样式：
   ```xml
   <style name="Theme.Kiosk.Forest" parent="Theme.Kiosk">
       <!-- 把 11 个皮肤 attr 全部指向 forest_* -->
   </style>
   <style name="Theme.Kiosk.Dialog.Forest" parent="Theme.AppCompat.Dialog.Alert">
       <!-- 同上，再加 windowBackground = @drawable/bg_dialog_forest -->
   </style>
   ```
4. `KioskTheme.kt` 的 `styleId()` 加一个分支，`displayName()` 加显示名
5. `MainActivity.showThemePicker()` 的 `values` / `names` 两个数组各加一项

完事。家长菜单里就能选到新皮肤，`recreate()` 后全局生效。
